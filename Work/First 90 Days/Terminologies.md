| **Pending**                          | Waiting for something to happen before the next step can proceed.                |

### Very Useful "Work Survival" Terms

| Term                 | Meaning / Explanation                                                                        |
| -------------------- | -------------------------------------------------------------------------------------------- |
| **Context**          | Background information needed to understand a situation.                                     |
| **Ownership**        | Responsibility for driving something forward and making sure it gets completed.              |
| **Visibility**       | Having enough information to understand what is happening.                                   |
| **Alignment**        | Shared understanding and agreement.                                                          |
| **Expectation**      | What someone believes should happen.                                                         |
| **Priority**         | The level of importance assigned to something.                                               |
| **Trade-off**        | Accepting one disadvantage or limitation in order to gain another benefit.                   |
| **Constraint**       | A limitation that affects what can be done.                                                  |
| **Gap**              | A difference between the current situation and the desired situation.                        |
| **Dependency**       | Something that another task or team relies on.                                               |
| **Bottleneck**       | A point in a process that slows down overall progress.                                       |
| **Root Cause**       | The fundamental reason a problem happened.                                                   |
| **Impact**           | The effect something has on the business, customer, project, or team.                        |
| **Effort**           | The amount of work required to complete something.                                           |
| **Capacity**         | The amount of work a person or team can realistically handle.                                |
| **Bandwidth**        | Available time or capacity to take on additional work.                                       |
| **Resource**         | A person, budget, tool, system, or other asset available for work.                           |
| **Escalation**       | Raising an issue to someone with greater authority or expertise.                             |
| **Exception**        | A situation that does not follow the normal process or rule.                                 |
| **Deviation**        | A difference from the expected standard, process, or plan.                                   |
| **Ad hoc**           | Something created or done for a specific situation rather than as part of a regular process. |
| **Proactive**        | Taking action before a problem or request occurs.                                            |
| **Reactive**         | Responding after a problem or request has occurred.                                          |
| **Iterate**          | Improve something through repeated versions or cycles.                                       |
| **Streamline**       | Simplify a process to make it more efficient.                                                |
| **Optimize**         | Improve performance or effectiveness.                                                        |
| **Scalable**         | Able to grow without requiring proportionally more resources or effort.                      |
| **Sustainable**      | Able to continue effectively over the long term.                                             |
| **Robust**           | Strong and reliable, especially under different conditions.                                  |
| **Seamless**         | Working smoothly without noticeable problems or interruptions.                               |
| **Granular**         | Very detailed or broken down into small parts.                                               |
| **High-level**       | General overview without detailed information.                                               |
| **End-to-end (E2E)** | Covering the entire process from beginning to end.                                           |
| **Bottom line**      | The most important conclusion or, financially, the company's net profit.                     |
| **Top line**         | Revenue or overall sales before expenses.                                                    |
| **Bottom-up**        | Starting with detailed information and building toward a broader conclusion.                 |
| **Top-down**         | Starting with a high-level direction and breaking it down into details.                      |
